# Contributing

1. Open an issue describing the problem or proposed change.
2. Keep local proxy and Worker security boundaries explicit.
3. Add tests for parsing, URL validation and access-control changes.
4. Run `cargo fmt --all -- --check` and `cargo test --workspace`.
5. Never commit tokens, private URLs, credentials or personal data.

Contributions are subject to the repository's proprietary license. A pull request does not grant redistribution or commercial-use rights.
